Notificaciones de Trabajo

Adjunta un Excel o pega la tabla (OT + denominación de objeto técnico). El sistema identifica el TAG de cada orden, lo asocia a su procedimiento P-SG y genera una plantilla de notificación .txt por cada OT, editable y descargable.

01

Cargar datos

Se lee la primera hoja. Columnas detectadas: OT, denominación de objeto técnico, número de equipo y fecha de inicio.

Prefijos reconocidos como TAG: PT, PIT, PI, PC, PIC, FI, FIC, FT, FC, LT, LI, LIC, LC, VSP, SV, SOV, AT, AI, OFD, HAD, FV, VTRC, HV, TE, TT, TI, TIC, TC, FE, LG, TIT, PV, LV, EX (las variantes con “I” de indicador —LIT, FIT, AIT— usan el mismo procedimiento que LT, FT y AT). El TAG es el primer dato que mezcla letras y números, aunque lleve delante el área (3110-PT-001). Si el pegado trae una fecha, se usa como fecha de inicio y de fin; los campos se rellenan con el caso normal y todo queda editable.

02

Mapeo TAG → Procedimiento

Agrega prefijos nuevos o corrige los existentes. Los cambios se guardan en este navegador y se aplican de inmediato a las órdenes cargadas.

Agregar / actualizar prefijo

Base de calibración (rangos, salidas y patrones)

Los datos de rango, salida y patrones utilizados salen de la base DPCTrack2. Para actualizarlos a futuro, genera el archivo datos_calibracion.json con src/extract_ranges.ps1 sobre la base nueva y adjúntalo aquí; se guarda en este navegador y se aplica a las órdenes cargadas. (El navegador no puede abrir el .mdb directamente, por eso se usa el archivo de datos.)

R

Generador de reporte de calibración

Digita el TAG de un instrumento y pulsa Buscar. Se cargan de la base sus datos (fabricante, serie, rango, precisión, patrones utilizados, etc.). Solo ingresas los valores de calibración (Enc. como / Dejado como): la salida nominal, el % de desviación y el resultado Aprobado/Fallado se calculan solos. Luego Generar reporte imprime un PDF con el mismo formato del informe de DPCTrack.
